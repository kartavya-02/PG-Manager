# PG Manager

A simple Progressive Web Application (PWA) designed to simplify PG management.

## Features
- Tenant management
- Rent tracking
- Electricity reading and charge calculation
- Payment records
- WhatsApp payment reminders
- Data backup and restore
- Installable Android application
- Offline support through service-worker caching

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web Apps (PWA)
- Cloudflare Pages
- PWABuilder
